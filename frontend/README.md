# ParkingBay - Park Smart, Explore More

Modern smart parking discovery and slot booking web application built with React, Node.js, and Tailwind CSS.

## Features
- **Sidebar Navigation**: Home, Map View, Parking List, My Bookings, Favorites, About Kolhapur, Help & Support.
- **Hero & Search Header**: Find parking in Kolhapur with search, city selector, and vehicle/amenity filters (All, Near Me, Car, Two Wheeler, Covered, Open, EV Charging).
- **Split View Layout**:
  - **Left**: Real-time list of parking spots with availability badges, slot counters, pricing (₹/hr), distances, and ratings.
  - **Right**: Interactive map with color-coded live status pins (Green = Available, Red = Full, Yellow = Limited, Blue = EV Charging), controls, and instant preview card.

## Getting Started

```bash
cd my-react-app
npm install
npm run dev
```
